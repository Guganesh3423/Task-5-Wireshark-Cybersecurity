# Task 5: Capture and Analyze Network Traffic Using Wireshark

## Objective
To capture live network packets and identify basic network protocols using Wireshark.

## Tools Used
- Wireshark 4.6.9
- Web browser

## Procedure
1. Opened Wireshark and selected the Wi-Fi network interface.
2. Captured live network traffic while browsing a website.
3. Examined the captured packets using Wireshark.
4. Identified the protocols shown in the packet list.
5. Saved the packet capture for analysis.

## Protocols Identified

1. **TCP (Transmission Control Protocol):** Provides reliable, ordered delivery of data.
2. **TLS (Transport Layer Security):** Protects data exchanged over supported encrypted connections.
3. **QUIC:** A transport protocol used by modern internet applications.
4. **DNS (Domain Name System):** Helps resolve domain names to IP addresses.

## Observation
The Wireshark capture displayed TCP, TLSv1.2, QUIC, and DNS traffic. A DNS query was also visible in the packet details.

## Conclusion
This task provided practical experience in capturing network packets, identifying protocols, and observing network traffic using Wireshark.
